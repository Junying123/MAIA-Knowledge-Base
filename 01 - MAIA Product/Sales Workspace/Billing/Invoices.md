# Invoices Module

**Location:** Sales → Invoices

**Purpose:** Create and manage customer invoices.

## Key Features

- Create from Sales Order or direct
- Multiple invoices per SO (partial billing)
- Cancel invoices
- Generate PDF
- Track payment status
