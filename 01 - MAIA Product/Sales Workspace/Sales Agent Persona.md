# Sales Agent Persona

**Name:** Adam Tan
**Role:** Sales Agent (Order Creation & Customer Interaction)
**Company:** Ultimax (medical/surgical supplies)
**Clients:** Hospitals — OR managers, surgeons, procurement officers

---

## Context

Adam sells **surgical sets and medical instruments** to 5–8 hospitals in the Penang region. He travels 70% of the time — working from his car, hospital lobbies, and between meetings. He is mobile-first and needs to quote, book, and coordinate on the spot.

---

## Daily Tasks

| Task | Frequency |
|------|-----------|
| Check overnight RFQs from hospitals | Every morning |
| Review upcoming operations (next 3–7 days) | Daily |
| Follow up on pending hospital quotation approvals | Daily |
| Check surgical set availability with warehouse | Daily |
| Prepare quotations (3–5 per day) | Daily |
| Send quotations via email/WhatsApp | Daily |
| Call hospitals to confirm operation dates | Daily |
| Visit hospitals for relationship maintenance | Regularly |
| Handle emergency booking requests (24–48hr turnaround) | As needed |
| Track delivery status pre-operation | Ongoing |
| Coordinate last-minute operation changes | As needed |
| Request set collections post-operation | 1–2 days after ops |

---

## Goals

### Short-Term (Daily/Weekly)

**Speed & Responsiveness**
- Quote from anywhere on mobile — close deals in the same conversation
- Handle urgent emergency requests without interrupting hospital visits

**Accuracy (Zero Tolerance)**
- Triple-check operation dates before booking (wrong date = lost client permanently)
- Confirm surgeon preferences every time (e.g., "Dr. Ahmad always wants Brand X")
- Verify warehouse preparation checklists before delivery

**Communication Efficiency**
- Get all info in first hospital conversation (avoid 3 follow-up calls)
- Send complete quotations hospitals can approve without clarification
- Use WhatsApp for delivery updates → hospitals stop calling to ask "where's our set?"

### Medium-Term (Monthly/Quarterly)

**Relationship Building**
- Be known by name at all 5–8 hospitals
- Build personal relationships with OR managers, procurement officers, key surgeons
- Have hospitals defend Ultimax when internal pressure to switch suppliers

### Long-Term (Career)

- Be recognized as top performer in the region
- Get promoted to Senior Sales or Team Lead
- Mentor new sales agents; document accounts so coverage during leave is seamless

---

## Key Pain Points

- Cannot afford to make date errors — a single mistake can lose a hospital permanently
- 70% travel makes desktop-only workflows painful
- Coordinating urgently with warehouse while in a hospital meeting is stressful
- Slow quote approval at hospitals blocks set booking

---

## Workflow Patterns

```
Hospital RFQ → Adam quotes on mobile → Hospital approves → Adam books set →
Warehouse prepares → Delivery before operation → Operation → Adam collects set
```

**Post-op loop:**
- Follow up on feedback 1–2 days after operation
- Request set collection
- Invoice and payment tracking

---

## Implications for MAIA OMS

- Must work well on **mobile** for on-the-go quoting
- **Fast quotation creation** is critical — minimize clicks
- **Real-time stock availability** check needed before quoting
- **Delivery tracking** visibility within the app
- **WhatsApp integration** or easy copy-to-WhatsApp for communication
