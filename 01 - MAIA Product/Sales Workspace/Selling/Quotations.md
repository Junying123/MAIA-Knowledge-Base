# Quotations Module

**Location:** Sales → Quotations

**Purpose:** Create and manage price quotations for customers.

## Key Features

- Create quotations with multiple items
- Set valid until dates
- Define payment terms
- Convert to Sales Orders
- Mark as LOST if customer declines
