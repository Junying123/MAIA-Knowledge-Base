# Daily Updates Index

This folder contains formatted daily updates for the MAIA PM team. Raw notes are written in Apple Notes (weekly note) and automatically formatted at 6pm Mon–Fri.

## How It Works

1. **5pm** — macOS notification reminds you to finalize raw notes in Apple Notes
2. **6pm** — Automation reads your Apple Note, formats it using the team template, and saves it here
3. Files are named: `Daily Update - DD-MM-YYYY.md`
