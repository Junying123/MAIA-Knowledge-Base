# Dev Handover Guide

Best practices for handing off user stories to the dev team.

## What Devs Need

- Clear user stories with acceptance criteria
- UI/UX mockups or references
- Business context and priority
- Expected delivery timeline

## Handover Process

1. Complete user story with all details
2. Review with dev team
3. Clarify questions
4. Track in project management tool

## Communication Tips

- Be specific about expected behavior
- Provide examples and screenshots
- Link to MAIA docs in KB
- Be available for questions
