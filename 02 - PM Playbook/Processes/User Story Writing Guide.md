# User Story Writing Guide

Guide for writing clear, testable user stories for the dev team.

## User Story Format

```
As a [role],
I want to [action],
So that [benefit].
```

## Acceptance Criteria

Use Given-When-Then format:

```
Given [precondition]
When [action]
Then [expected result]
```
