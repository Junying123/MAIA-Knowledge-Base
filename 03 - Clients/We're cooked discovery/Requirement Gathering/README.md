# Requirement Gathering

Deep-dive discovery notes captured by the PM **after** the discovery call with a potential client.

## Purpose

After the GTM Brief sets the scene, the PM runs a structured discovery session with the prospect to capture:
- Detailed current-state workflows (Sales, Logistics, Finance)
- Integration and data requirements
- Gaps vs. MAIA's current product
- A fit verdict: proceed / park / disqualify

## Folder Structure

Each prospect gets their own subfolder:

```
Requirement Gathering/
└── [Prospect Name]/
    ├── Requirement Gathering.md    ← main discovery doc
    └── Meeting Notes/              ← notes from each discovery call
```

## How to Use

1. After a discovery call is scheduled, create a subfolder: `[Prospect Name]/`
2. Copy `[[02 - PM Playbook/Templates/[Template] Discovery Requirement Gathering]]` → rename to `Requirement Gathering.md`
3. Read the GTM Brief first: `[[03 - Clients/Discovery Pipeline/GTM Briefs/[Prospect Name]]]`
4. Fill in all sections during / after the discovery call
5. Complete the **Fit Assessment** table
6. KB Lead reviews the fit verdict
7. If proceeding → graduate folder to `[[03 - Clients/Active Clients]]`
