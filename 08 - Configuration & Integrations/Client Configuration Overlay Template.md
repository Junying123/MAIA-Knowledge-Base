# Client Configuration Overlay Template

**Template for documenting client-specific configurations.**

This is a pointer to the actual template:

**Use:** [[02 - PM Playbook/Templates/[Template] Client Config Overlay]]

## Purpose

Client configuration overlays document:
- Client-specific settings that deviate from standard MAIA
- Custom workflows or processes
- Integration configurations
- User roles and permissions
- Business rules

## Where to Store

- Client configs live in: `03 - Clients/[Client Name]/`
- Use the template: [[02 - PM Playbook/Templates/[Template] Client Config Overlay]]
