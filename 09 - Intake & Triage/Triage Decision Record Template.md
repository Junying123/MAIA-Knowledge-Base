# Triage Decision Record Template

**Template for recording triage decisions.**

This is a pointer to the actual template:

**Use:** [[02 - PM Playbook/Templates/[Template] Triage Decision Record]]

## Purpose

Every triaged request gets a Triage Decision Record that documents:
- Request classification (Product/Config/Custom/Bug)
- Rationale for classification
- Next steps and owner
- Decision approval

## Where to Store

Triage Decision Records are stored in:
- `09 - Intake & Triage/decisions/[Request-ID].md`
