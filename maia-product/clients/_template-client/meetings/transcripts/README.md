# Meeting Transcripts

Use this folder for raw meeting transcript material only when it is useful to
keep locally.

## What belongs here
- Fireflies transcript markdown exports
- Granola transcript markdown exports
- Lark meeting note exports
- Link stubs that point to the original transcript source

## Rule
Do not treat this folder as the main working summary. Distill useful outcomes
into `../YYYY-MM-DD-meeting-synthesis.md` and record the source in
`../../source-map.md`.
