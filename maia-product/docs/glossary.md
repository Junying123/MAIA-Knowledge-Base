# Glossary

## Purpose
This glossary captures recurring internal terms, repo names, and working language used across the MAIA product environment.

## Terms

### MAIA
The main ERP + AI chatbot product environment worked on by the team.

### MAIA Product
The product-team working context layer, centered in the `maia-product` repo.

### MAIA CODEX
The formal implementation and product specification source of truth, centered in the `maia-codex` repo.

### Lark / Mindhive OS
The live operating layer for current status, dates, task tracking, ownership, and published documents.

### GTM
Go-to-market. Covers market-facing coordination such as sales and marketing.

### FE
Frontend.

### BE
Backend.

### Chatbot Team
The team focused on chatbot-related implementation and delivery.

### Source Of Truth
The system or repo that should be trusted for a specific category of information.

Examples:
- live status -> Lark / Mindhive OS
- formal implementation specs -> MAIA CODEX
- onboarding and working context -> `maia-product`

### Handoff
The transition from scoped context into implementation-ready delivery context.

### Client Context
The accumulated knowledge, scope, decisions, and relationship-specific details for a given client.

### Delivery Context
The practical information needed to move work from idea or request into execution.
