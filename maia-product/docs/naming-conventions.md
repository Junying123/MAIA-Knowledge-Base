# Naming Conventions

## Client slugs
Use lowercase kebab-case.

Examples:
- `holsen`
- `fixguru`
- `jdx`
- `macrofood`

## Dates
Use ISO date prefix: `2026-06-24-fixguru-uat-debrief.md`.

## Current docs
Stable current docs use `current-*`.

## Workflow folders
Use numeric stage prefix, e.g. `00-sales-product-handover/`, `07-core-uat/`.
