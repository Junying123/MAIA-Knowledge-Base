# Publishing Rules

## Draft vs published
- Local markdown starts as draft unless explicitly marked published.
- Lark is the official team reading destination.
- `published-links.md` must map local files to Lark destinations.

## Before publish
- Validate with `agent-ops/checklists/doc-quality-checklist.md`.
- Confirm owner/reviewer.
- Confirm destination.
- Confirm no unsupported claims.

## Never publish
- raw messy notes
- unverified client commitments
- inferred scope marked as confirmed
- credentials or private data
- docs with unknown source provenance
