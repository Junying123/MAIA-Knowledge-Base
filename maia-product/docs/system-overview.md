# System Overview

## Stack

```text
Lark Base / Wiki / Docs
        ↓ fetch via lark-cli
MAIA Product Context
        ↓ structured markdown + agent workflows
MAIA CODEX
        ↓ formal specs for dev/coding agents
Engineering delivery
```

## Layer responsibilities

### Mindhive OS / Lark
Live operational system: product tracker, tech tracker, owner, status, deadlines, official published docs.

### MAIA Product Context
Product team structured context workspace: client/account context, narratives, scope summaries, account plans, meeting syntheses, workflow-stage artifacts, source maps, validation checklists.

### MAIA CODEX
Implementation-spec layer: PRD, design, tasks, changelog.
